# LooterStudio®

Root company. Everything lives here: **stat**, **Brier.**, and whatever comes next.

Static site. No build step.

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

- `index.html` — single page
- `css/main.css` — black ground, mono HUD, Arial Black brand, silk-road green nav
- `js/main.js` — LOOT.exe manifesto cycler with scramble + RGB glitch, ticker, HUD
- `assets/loot-360.mp4` — 360° logo, square crop, seamless loop

Deployed with GitHub Pages from `main`.
